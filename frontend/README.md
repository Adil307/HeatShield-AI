# HeatShield AI — Frontend

Next.js 16 App Router UI for HeatShield AI. This folder is the UI deploy root. It is not yet wired to the backend API.

## Setup — Windows PowerShell

```powershell
cd frontend
npm install
```

## Start

```powershell
npm run dev
```

Open:

```text
http://localhost:3000
```

The homepage currently shows only **HeatShield AI**.

Do not put `FORTYGUARD_API_KEY` in this folder. The key stays in `backend/.env`.
